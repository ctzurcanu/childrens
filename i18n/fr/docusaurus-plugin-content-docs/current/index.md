# L’Internationale des enfants

## Qu’est-ce que c’est ?

Ce pourrait être :

- un parti politique international ;
- une méta-organisation ;
- un lieu d’amitié ;
- un moyen d’aider d’autres enfants ;
- l’espoir et l’imagination transformés en bien ;
- un monde pour les enfants.

## Ce que cela ne devrait pas être

- une œuvre de charité où les enfants doivent mendier des ressources ;
- un système permettant aux adultes de surveiller ou de contrôler les enfants.
